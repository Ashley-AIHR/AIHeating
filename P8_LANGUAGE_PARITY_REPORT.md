# P8 Language Parity Report

The evaluation contains 50 semantic IDs, each with one English and one Simplified Chinese case. Results were EN 50/50 and ZH 50/50 with zero semantic-pair failures.

Project terminology remains aligned: Required Heat Load / 所需热负荷, Actual Heat Supply / 实际供热量, Avoidable Oversupply / 可避免过量供热, Traditional Weather Compensation / 传统气候补偿, Building Thermal Prediction / 楼栋热状态预测, Formal MPC / 正式 MPC, Verified in Digital Twin / 已在数字孪生中验证, Verified Fallback / 已验证回退, Constraint Infeasible / 约束不可行, Safety Not Guaranteed / 无法保证安全, and Simulation Environment / 仿真环境.

The Tutor follows UI language by default. Browser automation also verified that an explicit English question entered under the Chinese UI receives an English answer.
