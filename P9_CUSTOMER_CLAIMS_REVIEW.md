# P9 Customer Claims Review

All supported claims apply to the **Synthetic Digital Twin PoC** and accepted held-out/canonical simulation evidence.

| Claim | Classification | Release wording / action |
|---|---|---|
| Formal MPC reduces heat use in Rapid Warming versus Traditional | SUPPORTED WITH QUALIFIER | Simulation-based comparison only; cite accepted MWh values and scenario. |
| Pump electricity is lower in the Rapid Warming comparison | SUPPORTED WITH QUALIFIER | Report separately as synthetic simulation, not a tariff or site saving. |
| Formal MPC reduces overheating/oversupply | SUPPORTED WITH QUALIFIER | Supported for accepted synthetic scenarios; no universal or field claim. |
| P4 accurately predicts real-site heat demand | UNSUPPORTED / REMOVE | Say “held-out synthetic simulation evaluation”; do not call metrics field accuracy. |
| P5 predicts building temperature for the PoC horizon | SUPPORTED WITH QUALIFIER | Effective H/C grey-box, synthetic calibration and stated uncertainty limitations. |
| Comfort is guaranteed | UNSUPPORTED / REMOVE | Report measured simulation compliance/comfort only. |
| Candidate/fallback is guaranteed safe | UNSUPPORTED / REMOVE | Use “Verified in Digital Twin” or “Verified Fallback”; preserve “Safety Not Guaranteed”. |
| Formal MPC optimises the accepted supervisory problem | SUPPORTED | State bounds, horizon, objective and verification; do not imply global or production optimality. |
| MPC improves hydraulic/thermal distribution using zone valves | SUPPORTED WITH QUALIFIER | Synthetic network only; small valve reversals remain. |
| Hydraulic Imbalance is the primary AI benchmark | UNSUPPORTED / REMOVE | It is a secondary engineering benchmark for coupling/redistribution/valves. |
| AI Tutor is a live generative LLM | UNSUPPORTED / REMOVE | Call it “Deterministic Grounded Tutor v1” / “Grounded PoC Explanation Assistant”. |
| Tutor is evidence-grounded and non-controlling | SUPPORTED | P7 structured context + curated knowledge; no DOM scrape/control callback. |
| The PoC is automated live control | UNSUPPORTED / REMOVE | Official mode is guided validated evidence replay; live runtime is deferred. |
| The method is applicable to a future site pilot | SUPPORTED WITH QUALIFIER | Architecture and staged transition are relevant; performance transfer is unproven. |
| The release is deployment/production ready | UNSUPPORTED / REMOVE | Customer demonstration RC only; no PLC/DCS, real sensors, interlocks or certification. |

## Required vocabulary

Use: Synthetic Digital Twin PoC, Held-out simulation evaluation, Formal Supervisory MPC, Verified in Digital Twin, Simulation Environment, Predicted Required Heat Load, Building Thermal Prediction, Verified Fallback, Safety Not Guaranteed.

Do not use: Production-ready AI Heating, Guaranteed Savings, Guaranteed Comfort, Guaranteed Safety, Real-world validated accuracy, Autonomous real-site control.
