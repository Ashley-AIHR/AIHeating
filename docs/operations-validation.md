## Deployment limitations

The Docker base image was found in the registry, and the pinned numerical dependencies resolved for Linux x86-64. The complete container image was not built or run locally because the Docker daemon was unavailable. No Render deployment was performed or verified.

The Vite build reports a non-failing warning about the lazy Three.js chunk exceeding 500 kB before compression; it is approximately 146 kB gzipped. The 3D code is lazy-loaded separately from the main interface and legacy dashboard.

This validation is functional research-prototype testing, not load testing, penetration testing, accessibility certification, a model accuracy assessment or a plant commissioning report. Model uncertainty remains unquantified and all telemetry is synthetic.
